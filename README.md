# 画心 · 本地书画图片整理工作台

双击 `启动画心.cmd`。浏览器打开 `http://127.0.0.1:8765`，图像处理和数据均在本机完成。

## 操作

界面：导入图片与导入文件夹统一位于右上角；左侧为作品库、搜索和筛选。右侧“四角裁剪 / 效果对比”使用深绿色选中块显示当前模式。常用区保留缩放、撤销和底部确认按钮；画面参数、分步裁剪与导出格式收进折叠面板。中间画布保持原有可用高度，文件名旁显示原图像素尺寸。左右方向键翻图，Shift＋方向键微调角点。

导入时保留完整原图，不自动识别、裁剪或收边。点击右侧“当前裁剪”后，才对当前图识别画心、原图精定位、透视校正并计算窄残边收边；右侧“全部裁剪”可统一处理未确认图片。分步精定位、候选和四边微调位于“高级调整”。边界证据弱时显示建议检查提示；此提示为启发式检查，不代表已测得准确率。重跑前参数保存在项目的 before_auto 字段，当前页操作可撤销。

后台仅准备预览缓存，启动、刷新与翻图均不会自动修改裁剪四角或收边参数。已有图片保留其已保存的处理结果和手动调整。当前图可通过右侧“当前裁剪”按钮处理或重跑。

裁剪边界优化（2026-10-23）：低色差纸面候选增加沿整条边的纹理过渡验证，只有多数分段支持时才调整，向内调整遇到明显笔画或印章会保留原边。靠近照片顶部的倾斜边线扩大精定位搜索，失败时退回原局部搜索。印章保护包含边线外侧邻近的淡红印章，并保留小幅安全距离。无法可靠识别时提示复核；同色装裱、纸内格线及不完整纸边仍可能误判。已有 crop_reference 的作品继续采用人工复核坐标，算法升级不会自动覆盖这些坐标。

加载流程已更新：服务启动时后台准备整个图库，导入返回前已保存原图并准备预览缓存，底部显示后台准备进度。翻图只读取已保存结果，不再现场跑识别。适合窗口时加载 1600 像素预览，放大时异步升级原尺寸细节图；几何坐标始终使用原图。浏览器预读相邻图片并保留有限数量的解码缓存，处理效果缓存按参数版本区分，修改后不会读到旧结果。导出仍从原图计算。

原图上的黄色四角框显示收边后的最终裁剪范围，与效果图一致。拖动角点或键盘微调时会将收边合入四角坐标，避免二次收边；撤销可恢复原来的四角及收边参数。

1. 添加图片、拖入图片，或者导入文件夹。支持 JPEG、PNG、TIFF（第一帧）、BMP、WEBP。
2. 导入后保留整张照片。需要识别时点击右侧“当前裁剪”，也可切换候选边界。可以直接拖动四角，依次为左上、右上、右下、左下。
   识别会结合纸面色调、细微纹理和四边连续性；密集笔画先从纹理评分中排除，避免将正文当成装裱。文件名尺寸仅辅助筛选不完整直线，不会强制改变清晰纸边。多色拼接作品会合并对齐的纸面候选，保留题头和下部正文。自动识别后会沿候选边读取原图像素，在附近分段寻找连续纸边并重新拟合。也可先手动拖到边缘附近，再点击“原图精定位当前边界”。保留精定位前的候选供恢复；弱边缘不强行移动。局部搜索最多约 48 个原图像素，不能纠正远离画心的粗定位，仍需检查贴边笔画。
3. 使用“效果对比”查看校正后的画面。亮度、对比度、清晰度默认均不增强。
   “去残边”比较外侧连续边带与相邻纸面的颜色差异，包含黄边、蓝边、白边等；按沿边各段的纸色和局部稳定程度判断。每边支持 0–5%，自动检测的搜索深度另受短边 5% 和 100 像素限制。近黑笔画跨越拟裁区域时保留该边；孤立印章不作为连续残边。低对比、同色装裱、深色花纹仍可能识别不准，可用高级调整微调或恢复。预览、选框与原尺寸导出均应用相同收边参数，不展开弯曲纸张。
4. 检查落款、印章和贴边笔画后，点击“确认当前作品”。修改参数会取消确认状态。
5. 点击右上角“导出已确认作品”，选择 PNG 无损或 JPEG 高质量格式。完成后打开导出文件夹。

精细调整：选择原图 100%、200% 或 400%，拖动画面平移；Ctrl＋滚轮可围绕鼠标缩放。选择角点后点击“定位”，直接跳到对应角点。箭头按钮或 Shift＋方向键按原图 1/5/10 像素步长微调。左右方向键切换作品（输入框和下拉菜单内保留原有按键行为）。“撤销”恢复当前图片最近一次参数修改。旋转会恢复整图边界，需要重新选四角。

## 数据

- `data/originals/`：导入图片的副本。源文件不修改。
- `data/project.json`：图片清单、裁剪坐标、参数、确认状态。自动保存，重新打开可以继续。
- `data/exports/时间_编号/`：每次独立导出目录，附带 `处理记录.json`。
- 原图和导出图均使用 EXIF 校正后的方向。四角编辑加载原尺寸 PNG 细节图，效果预览最长边缩至 1600 像素；导出从原图计算，不使用预览图。
- 透视校正输出尺寸取所选四边的像素长度，未引入 AI 放大或整图重绘。

## 折痕和凸起修复

顶部切换“2 折痕修复”，这里只显示已确认裁剪的图片。修复在原尺寸裁剪图上进行。画布左上角提供缩放按钮、100% 和适合窗口；滚轮围绕鼠标位置缩放，最高 800%。按住空格拖动、鼠标中键拖动，或选择“移动画面”平移。松开空格后即可继续框选，缩放不会改变选区的原图位置。拖动框选区域后生成预览，检查文字、印章后采用，也可放弃、撤销或重做。完成后点击“确认成品 / 无需修复”，再导出成品。更改裁剪参数会使旧修复失效，旧记录保留但不会套用到新裁剪。

常规修复完全在本机运行，主要平衡选区内折痕、凸起的明暗，不会真正展平纸面几何形变。算法尽量保护深色墨迹和异色印章，但仍应人工检查淡墨和复杂纹理。

新标记默认“标准”。第一次框选并选好类型或完成涂抹后，自动在选区外提示“轻度 / 标准 / 加强”；周围没有空位时改为在右侧列表展开，不挡住选区，不选择即保持标准。右键菜单也可直接修改强度。右侧标记列表分为位置名称、等级按钮、删除按钮：点名称仅高亮定位，放大时滚动至标记中心并保留缩放；点等级按钮在列表内展开三档选项，普通选中不会重复弹出首次提示。三档常规修复分别使用 30% / 65% / 100%，每处独立保存，折痕、凸起和瑕疵均可设置。右侧百分比保留供旧的无独立等级标记使用。在对比卡片中切换等级后，点击该处“重新修复”才生效，其余候选保留；失败时保留旧等级和旧预览。AI 使用对应等级的文字要求，实际效果仍需审核。标记列表的“删除全部”仅清空当前作品的待修复选框和涂抹，不撤销已采用的修复。

右侧工具栏提供“涂抹 / 橡皮擦 / 框选 / 移动 / 圈瑕疵”五种工具，默认为“涂抹”：
- **涂抹（默认）**：先在笔刷面板选择类型（折痕 / 凸起 / 瑕疵）并调节笔刷粗细（4–200 px，支持快捷键 `[` 缩小、`]` 放大，画面上显示随缩放变化的圆形笔刷光标），再直接在折痕或凸起处涂抹。每一笔自动生成一条对应类型的标记，无需再弹出分类框；修复时仅作用于涂抹笔画内部（边缘平滑羽化）。
- **自动吸附到折痕**：默认开启，松开鼠标后沿笔迹逐段、在笔刷半径的 70% 范围内搜索（最多 48 原图像素）。结合局部方向、亮暗两侧和连续性定位，避开墨迹、印章；不可靠的段落保留原涂抹。只有整条路径均可靠时才收紧笔刷宽度。复杂交叉折痕仍建议放大检查。
- **橡皮擦**：擦除已涂抹笔画的局部（长线段自动加密采样，可从中间擦断或修整边缘），擦空后自动移除该标记。
- **框选**：适合大面积凸起或阴影。每次拖动完成新选区，选区旁会弹出“折痕 / 凸起 / 瑕疵去除”；先选择本次选区的类型，再点击常规修复或 AI 修复；未选择不会提交，也不会默认为折痕。重新框选时分类清空，需为新选区重新选择。

选择类型会将该区域加入本图的标记清单，不会立即修复。折痕为橙色、凸起为蓝色，显示序号和分类；可以继续框选多处。标记的坐标、分类和裁剪版本保存在项目中，刷新或切换后可继续。点击列表或画面上的标记标签可选中，通过“修复内容”修改类型，× 删除单个标记。全部标好后，常规修复或 AI 修复会处理当前作品的全部标记；不会自动处理其他作品。

AI 按标记逐个发送局部上下文与遮罩，指令包含序号、类型和原图归一化坐标。折痕处理细窄亮脊和暗线，凸起处理较宽的明暗渐变；两者都要求保护笔画、落款、印章、纸色和纹理，不补写无法辨识的文字。每个区域可能产生一次 AI 调用费用。实际代理模型的修复质量仍需检查预览后决定是否采用。

顶部“批量 AI 修复”提供作品勾选窗口：选一幅就是单张，选多幅统一后台处理。窗口显示作品数、标记数及同时处理数量（1 或 2 幅），点击开始前不调用 AI。当前作品的单张 AI 按钮也保留。任务列表显示排队、处理中、待审核和失败；结果不会自动采用或替换原图。停止只影响尚未开始的作品，正在调用的作品会完成并可能计费。失败作品可重新选择提交，不会自动重试收费。已采用且标记未变化的区域不会再加入批量任务。

队列和待审核预览保存在本机。重启后可以继续审核已经完成的结果；中断的任务需要手动重新提交，不会后台自动重新调用。处理期间改了裁剪、底图或标记，旧结果会失效。单张预览也会持久保存内部记录，但批量任务结果通过任务列表集中审核。

像素保护：最终 PNG 采用裁剪图原始宽高，框外像素由原图拷贝，不使用 AI 整图结果。发送给 AI 的局部上下文先补足画布比例，不拉伸输入；返回图比例异常时直接拒绝，避免强行拉伸字体。对选区内深色笔画/印章位移和明显纸色色偏进行保守检测，异常结果不保存为可采用候选。该检测是启发式，可能误报，也不能发现全部淡墨、细节变形或局部色差，必须审核前后对比。AI 内部处理可能影响选区细节，保留相同像素尺寸不等于保证细节零损失。

框选后点击“修复选区”，画布右侧立即出现结果框和加载状态，左侧图片与选区保持不变。成功后默认展示选区及周围细节，可切换查看完整作品；采用和放弃按钮位于结果框底部。失败会在框内显示原因，可直接重试，未采用的候选不会覆盖当前图片。

结果框显示本次修复前、修复后的同一区域对照。局部细节与完整作品均支持滚轮、＋/－、100% 和适合窗口，最高 800%；拖动任意一张对比图，两边联动。横向选区上下显示，竖向作品左右显示。对比中的“修复前”为本次操作开始前的已采用结果，避免多次修复后误拿最初版本比较。

AI 连接支持可编辑 Base URL、Key 和图像编辑模型，默认代理地址为 `http://127.0.0.1:8317/v1`。点击“保存连接”后配置保存在 `data/ai-connection.json`，Key 通过 Windows DPAPI 以当前账户加密，不写入明文，重启后自动读取；配置接口不会回显 Key。换电脑或 Windows 账户后可能需要重新填写 Key；非 Windows 系统不会退回明文保存。此文件随 `data/` 排除在 Git 之外，也不通过网页文件接口提供下载。点击 AI 预览时，才会向所配置服务发送选区和周围上下文。检测模型列表成功不等于支持图像编辑：代理和模型必须兼容 `POST /images/edits`，支持 PNG 图像、透明遮罩和 base64 图像响应。聊天模型名不能据此假定可用于图片修复。实际调用可能收费，需检查 AI 是否改动了笔画。

修复结果和无损历史保存在 `data/repairs/`，源文件不修改。尚未进行真实代理 AI 调用验收；本地流程和模拟图像接口已测试。

## 当前范围

已实现本地批量整理、人工复核和独立局部修复工作区。自动检测综合 OpenCV 轮廓、纸面颜色、纹理和长边，沿边细化。收边检查整个待删除区域里的墨迹和红印章，避免小印章被大片空白稀释；最终四角还检查跨边界的连通笔画，在有限范围内外移并提示复核。这些启发式保护不能保证识别全部淡墨、朱印或极小笔画；复杂背景、同色装裱、多幅作品仍可能需手动调整。没有文字识别和自动去背景，扇形仅提供矩形裁剪。没有声称自动检测正确率。

逐张复核的例外边界可保存在作品的 `crop_reference` 中。再次显式裁剪时，仅在原文件与旋转方向一致时应用，界面显示“已应用逐张复核的纸边”；这不属于自动识别成功。复核边界不额外收边，不替用户确认作品，已确认作品不覆盖。

目前为本地网页应用，可从启动文件打开，尚未打包为独立 EXE。关闭网页后本地服务继续运行，以便重新打开和完成导出。

## 换电脑部署

安装 Python 3.11 或以上，在此目录执行：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

再双击启动文件。此电脑会优先使用项目虚拟环境，否则使用已有的 Python 运行环境。开发测试：`python test_app.py`。本机有原图库时可运行 `python test_dataset_crops.py` 检查已标注的实图回归；`python audit_crops.py` 会把整库新旧选框对照写入 `data/crop-audit/算法版本/`，不会修改图库。整库运行成功不等于逐张边界验收通过。

服务只监听 127.0.0.1；写入请求要求页面会话令牌。不要将此服务转发到公网。

AI repair: GPT conversational models use Responses with image_generation and a mask; image models use images/edits. Both preserve detected dark ink/red seals and composite only editable paper pixels, with feathered boundaries and aspect/ink checks. Detection is heuristic, so faint ink still requires visual review.
